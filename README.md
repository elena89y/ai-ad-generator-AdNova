## 📌 프로젝트 개요

소상공인과 온라인 판매자는 상품 홍보를 위해 광고 이미지를 제작해야 하지만, 전문 디자인 툴이나 마케팅 경험이 부족한 경우가 많습니다.

본 프로젝트는 **생성형 AI**를 활용하여 사용자가 업로드한 **상품 이미지**를 기반으로, 제품은 원본 그대로 보존하면서 배경·조명·무드만 광고에 어울리게 재구성한 **광고 이미지**와 **광고 카피**를 자동 생성하는 서비스를 제공합니다.

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | AI Ad Generator (AdNova) |
| 대상 사용자 | 소상공인, 자영업자, 온라인 셀러, 마케터 |
| 기간 | 2026.07.01 ~ 2026.07.30 |
| 핵심 기능 | 상품 이미지 기반 광고 이미지 생성 및 광고 카피 생성 |
| 배포 | https://adnova.iridescentseraphim.org/ |

## ✨ 주요 기능

- 🔐 소셜 로그인 (Google / Kakao / Naver)
- 🖼 상품 이미지 업로드
- ✨ 자동 전처리 (배경 제거 / 리사이즈 / 품질 보정)
- 🎨 6종 스타일 프리셋 (모노톤 · 웜빈티지 · 팝비비드 · 에디토리얼 · 리얼리즘 · 파스텔 플로팅)
- 🧠 AI 스타일 추천
- 🖌 인페인팅 기반 광고 이미지 생성 (제품 원본 보존, 배경만 재구성)
- 📝 AI 광고 카피 생성
- 🔄 광고 재생성
- 📂 생성 이력 관리
- 📤 채널별 맞춤 Export (SNS / 카드뉴스 / 배너 / 상세페이지 / 전단지)
- 🗂 템플릿 50종 제공
- 💳 크레딧 기반 요금제 (Free / Premium)

## 🛠 기술 스택

| 구성 요소      | 기술                                                |
| -------------- | --------------------------------------------------- |
| Frontend       | Next.js                                             |
| Backend        | FastAPI                                             |
| Authentication | OAuth (Google / Kakao / Naver) + JWT + bcrypt       |
| AI Preprocess  | rembg (u2net, ONNX / GPU 가속)                      |
| AI Image       | OpenAI Image API (Inpainting 기반) + Local model    |
| AI Copy        | OpenAI GPT (Vision / BLIP 캡셔닝)                   |
| Database       | SQLite                                              |
| Reverse Proxy  | Nginx (HTTPS)                                       |
| Deployment     | Docker + GCP                                        |

## 🧩 서비스 구조

```
상품 이미지 업로드
        │
        ▼
자동 전처리 (배경 제거 / 리사이즈 / 품질 보정)
        │
        ▼
스타일 결정 (AI 추천 or 프리셋 선택 or 직접 입력)
        │
        ▼
Prompt Builder
        │
        ▼
OpenAI Image API (Inpainting)
        │
        ▼
광고 이미지 생성
        │
        ▼
OpenAI GPT
        │
        ▼
광고 카피 생성
        │
        ▼
채널별 Export (SNS / 카드뉴스 / 배너 / 상세페이지 / 전단지)
```
상품 이미지 업로드
        │
        ▼
① 이미지 전처리 (FR-06)
   배경 제거(rembg) · 리사이즈 · 품질 보정 · 제품 마스크 생성
        │
        ▼
② 광고 스타일 결정 — 2경로 (FR-05)
   경로1: Vision 분석 → 스타일 후보 3개 추천 → 유저 선택
   경로2: 유저 자유 텍스트 입력 → 스타일 결정
        │
        ▼
   Prompt Builder (FR-07)
   상품 정보 + 스타일 → positive/negative 프롬프트
        │
        ▼
③ 광고 이미지 생성 (FR-08)
   SDXL Inpainting — 제품 보존(마스크) + 배경 교체
        │
        ▼
④ 광고 카피 생성 (FR-09)
   생성된 광고 이미지 기반 — BLIP 캡션(저비용) / Vision(검증·데모)
        │
        ▼
최종 광고 콘텐츠 (이미지 + 카피)
```

> 스타일(문구 톤·색상: 모노톤/웜빈티지/팝)과 용도(채널·목적: SNS/카드뉴스/배너/상세페이지/전단지)는
> 별개 축으로 분리되어 있습니다. 자세한 실험 기록은 실험로그 문서를 참조하세요.

## 📡 API

| Method | Endpoint | 설명 |
| --- | --- | --- |
| GET | /auth/oauth/{provider} | 소셜 로그인 (google / kakao / naver) |
| POST | /auth/logout | 로그아웃 |
| POST | /images/upload | 상품 이미지 업로드 |
| POST | /images/process | 상품 이미지 전처리 |
| GET | /style/recommend | AI 스타일 추천 |
| GET | /style/presets | 스타일 프리셋 목록 조회 |
| POST | /ads/generate | 광고 이미지 생성 |
| POST | /ads/regenerate | 광고 재생성 |
| POST | /copy/generate | 광고 문구 생성 |
| GET | /templates | 템플릿 목록 조회 |
| GET | /history | 생성 이력 조회 |
| POST | /export | 채널별 Export |
| GET | /credits | 잔여 크레딧 조회 |
| POST | /credits/deduct | 크레딧 차감 |
| POST | /billing/upgrade | 프리미엄 업그레이드 |

> ⚠️ 위 API 명세는 실제 배포 사이트 기능 기준으로 재구성한 것으로, `backend/app/api` 폴더의 실제 코드와 이름이 다를 수 있습니다. 배포 전 최종 확인이 필요합니다.
